# AI OS

Cross-platform AI OS project.

## Target Platforms

- Web: Next.js + TypeScript
- Desktop: Windows, macOS, Linux
- Mobile: Android, iOS, iPadOS
- Server: Linux + Docker

## Architecture

- Backend: FastAPI
- Database: PostgreSQL
- Cache / Queue: Redis
- Server Agent: Python
- Client: Flutter shell + cross-platform Client Core/Agent
- AI Layer: Cloud LLM + Local LLM abstraction

## Development Machines

- Milad: MacBook M4 — development server, Docker, backend, server agent, AI/LLM, macOS/iOS builds
- Ashkan: Lenovo Windows — web, Flutter, Windows client, client agent
